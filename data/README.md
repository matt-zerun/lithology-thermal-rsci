# Public demonstration data

`synthetic_example.csv` is deterministic synthetic data generated by
`scripts/generate_synthetic_example.py`. It does not reproduce, resample, or
approximate any restricted reference observation.

The hierarchy is intentional:

- multiple thermal-conductivity measurements map to selected material states;
- each `material_id` contains more than one achieved state;
- each `parent_material_id` contains more than one material member;
- every lithology contains enough parent-material groups for five-fold outer
  and three-fold inner grouped cross-validation.

This makes the example suitable for testing state aggregation and
parent-material-grouped validation. Metrics obtained from it are demonstration
results only and must not be compared numerically with the frozen reference-analysis
outputs.

`templates/rsci_canonical_observations_template.csv` is the blank input
template. `input_schema.csv` and the root `DATA_SCHEMA.md` define required
fields, optional dry/particle densities, and optional
`measurement_temperature_c`. These optional quantities are not predictors.

Aggregation creates `material_state_id`, `thermal_conductivity_sd_w_mk`,
`thermal_conductivity_min_w_mk`, `thermal_conductivity_max_w_mk`, `measurement_count`, and
`first_observation_id`. `measurement_count` records the number of conductivity
measurements mapped to a state; it does not assert that
all contributing measurements are technical replicates. The reference-analysis
record-level dataset is not included.
