# Data availability and reproducibility boundary

## This code-only GitHub repository includes

- Python source for the computational model and diagnostic workflow;
- model, tuning and RSCI configurations;
- synthetic observations (deterministically fictional), schema and input template;
- automated tests and synthetic-data validity checks;
- documentation, package metadata and the MIT license.

## Available only in the complete Zenodo archive

- frozen aggregate numerical tables from the restricted reference analysis;
- publication/supplement figures and publication-output generators;
- selected response-surface grids and profiles from the reference analysis;
- reference-output quality checks and complete-release metadata.

Zenodo software concept DOI: https://doi.org/10.5281/zenodo.21682909.
Do not infer the publication status of Zenodo version 2.0.1 from this file.

## Restricted and not distributed in either public package

- record-level laboratory and harmonised-literature observations;
- parent-material mappings and record-specific state identifiers;
- group/fold assignments, record-level withheld predictions;
- inner-fold tuning records and fitted reference-analysis models.

Users may run this pipeline on the included synthetic data or their own
**authorised and screened** canonical observations. This is implementation-level,
not full raw-data reproducibility of the archived reference analysis.
